# Contributing

Thanks for contributing! This package is a plugin for the
[HKM Kernel](https://github.com/AlfaCode-Team/hkm-kernel) Gated Demand Architecture framework.

- Open issues and pull requests against **this** repository.
- `composer install` then `vendor/bin/phpunit` and `vendor/bin/phpstan analyse`.
- Follow PSR-12 and keep code within the framework's five access rules
  (API / Application / Domain / Infrastructure boundaries).
- **Security issues:** do not open a public issue — see [SECURITY.md](SECURITY.md).
